# Level 2: Intermediate Architecture Roadmap

Five practical backend engineering projects covering authorization, business logic, transactions, relationships, background processing and API integrations.

## Project Sequence
- **Project 06:** [Role-Based Access Control System](./projects/06-role-based-access-control-system/) — RBAC, granular permissions, access policies, resource ownership verification
- **Project 07:** [E-commerce Backend API](./projects/07-ecommerce-backend-api/) — Complex logic, cart state, inventory locking, ACID database transactions, payment sandbox
- **Project 08:** [Blog and Content Management API](./projects/08-blog-content-management-api/) — One-to-many, many-to-many relationships, comments, tags, search, soft deletion
- **Project 09:** [Notification Service](./projects/09-notification-service/) — Background worker jobs, job queues, email delivery, retry mechanisms, failure handling
- **Project 10:** [API Integration and Webhook Platform](./projects/10-api-integration-webhook-platform/) — Third-party API consumption, webhook receivers, signature verification, rate limiting, retries
